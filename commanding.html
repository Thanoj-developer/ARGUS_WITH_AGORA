📋 How to Get a Free NVIDIA NIM API Key
  1. Go to build.nvidia.com and sign up / log in.
  2. Click on any model (e.g. meta/llama-3.1-8b-instruct).
  3. Click "Get API Key" → Copy the key starting with nvapi-
  4. Paste it in the field above and click Save & Apply.
  5. ✅ Free tier includes ~1000 requests/month per model. No credit card required.
